info Understanding Academic Level

The Level is a numeric rank that reflects where this class sits in your school's academic progression. It is used for:

  • Promotion rules — the system uses level to figure out which class to promote a student to next year.
  • Reports & sorting — class lists are automatically ordered by level so lower grades appear first.
0Nursery / Pre-KG
1LKG / Class 1
5Class 5 / Grade 5
10Class 10 (Matriculation)
12Class 12 (Senior Secondary)
15Diploma / Advanced

lightbulb Tip: Use 0 for pre-school classes. Levels 1–10 suit most K–10 schools. Use 11–15 for higher secondary or diploma programmes.
