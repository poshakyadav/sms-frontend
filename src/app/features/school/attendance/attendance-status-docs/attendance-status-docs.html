📋
When in doubt, escalate

If you are unsure which status to use in an unusual situation, mark ABSENT temporarily and consult the principal or admin office. An incorrect status — especially EXCUSED or SUSPENDED — can have legal and regulatory consequences. It is always safer to use a conservative status and correct it later with documentation than to use a lenient one without authority.
